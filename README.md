# 한국 KOSPI200 기업 분석 데모

🇰🇷 한국어 · 🇬🇧 [English](README.en.md)

한국 KOSPI200 에 속했던 대형주(10년간 321곳, 상장폐지 포함)의 재무 상태와
시장 분위기를 한눈에 보여주는 도구입니다. 종목 하나를 고르면 재무 건강 +
시장 상황 + 종합 해석을 함께 표시합니다. 모델의 한계도 솔직히 함께
보여주는 시연용 데모입니다.

> ⚠️ **본 시스템은 시연용 데모입니다. 실제 투자에 사용하지 않습니다.**

![대시보드 개요](docs/images/overview.png)

## 무엇을 보여주나요?

1. **종목별 분석** — 관심 회사 (예: 삼성전자) 의 재무 건강 + 시장 상황 +
   종합 해석
2. **시장 상황** — 한국 시장의 시점별 분위기 (위험회피 / 중립 / 위험선호)
3. **한계 안내** — 모델의 솔직한 한계와 데모임을 명시

어두운 금융 리포트 톤의 화면에서 차트와 카드로 정리해 보여줍니다.

## 어떻게 만들었나요?

Claude 와 함께 만든 프로젝트입니다.

- 분석 기간(2015–2024년) 중 KOSPI200 에 속했던 기업 321곳의 재무제표·주가 데이터 사용
- 머신러닝 모델로 위험 점수와 시장 상황 분류
- 언어 모델(LLM)은 *이미 검증된 수치를 시장 상태에 맞춰 풀어 쓰는 서술
  보조*로만 사용합니다 — 수치를 결정하지 않습니다. 해석 문장은 빌드
  타임에 1회 생성해 고정하며, 웹 페이지 실행 중에는 호출하지 않습니다.
  현재 시가총액 상위 40 종목에 생성돼 있고, 나머지 종목은 기본 틀
  문장으로 표시됩니다.
- 웹 페이지 (Streamlit) 로 결과 표시

자세한 기술 자료는 [방법론 문서](docs/methodology.md) 와
[`reports/`](reports/) 의 모델 카드 참조.

## 왜 이렇게 만들었나요? — 설계 Q&A

**Q. 왜 재무 분석을 시장 상황과 함께 보여주나요?**
같은 재무 변화라도 시장 분위기에 따라 다르게 읽혀야 한다고 봤기
때문입니다. 예를 들어 같은 부채 증가라도 위험회피 시장에서는 더
주의해서 봐야 합니다. 그래서 해석 문장도 시장 상태 조건부로 생성합니다.

**Q. 왜 상장폐지된 회사까지 포함하나요 (321곳)?**
지금 살아남은 종목만 보면 부실 사례가 표본에서 사라지는 *생존 편향*이
생깁니다. 그래서 분기별 시점의 KOSPI200 구성과 분석 기간 내 상장폐지
종목을 합쳐 *"그 시점에 KOSPI200 이었던 기업"* 을 그대로 봅니다.

**Q. 왜 언어 모델(LLM)은 미리 한 번만 실행하나요?**
수치는 머신러닝·통계 단이 결정하고, LLM 은 이미 검증된 수치를 한국어로
풀어 쓰는 서술 보조만 맡습니다. 빌드 시점에 1회 생성해 고정하면 비용이
예측 가능하고 결과가 재현되며, 웹 페이지 실행 중 LLM 호출이 0회라는
것은 CI 가 검사합니다.

**Q. 왜 Python 인가요?**
데이터 수집 (DART·pykrx·FinanceDataReader) 부터 모델 학습
(scikit-learn·LightGBM·hmmlearn), 웹 화면 (Streamlit) 까지 전 단계를
한 언어의 생태계로 이어 붙일 수 있어서입니다.

**Q. 왜 실시간이 아니라 과거 데이터 배치 분석인가요?**
본 시스템은 시연용 데모라 결과의 재현 가능성이 우선입니다. 실시간
처리·정밀 주가 예측·트레이딩은 처음부터 범위 밖으로 못 박았습니다.

**Q. 모델 성능이 좋지 않은데 왜 그대로 보여주나요?**
위험 모델의 성능 (PR-AUC) 은 무작위 기준선보다 낮게 나왔습니다. 이는
KOSPI200 처럼 부실 사건이 희소한 모집단의 한계를 보여주는 정량 증거라,
숨기지 않고 모델 카드와 한계 페이지에 그대로 기록했습니다.

## 실행 방법

```bash
# 환경 설정
uv sync --frozen

# API 키
cp .env.example .env
# DART_API_KEY=... 채우기

# 데이터 수집
uv run python scripts/collect_data.py

# 모델 학습
uv run python scripts/train_d2_baseline.py
uv run python scripts/train_regime.py

# (선택) 해석 문장 생성 — GEMINI_API_KEY 를 .env 에 추가 후 실행.
# 건너뛰어도 동작합니다 (해당 종목은 기본 틀 문장으로 표시).
uv run python scripts/generate_interpretations.py --scope latest --order marcap --limit 40

# 웹 페이지 실행
uv run streamlit run app/main.py
```
